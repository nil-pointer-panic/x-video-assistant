# X 视频助手 / X Video Assistant

A Chrome extension that enhances video playback and downloads on X (formerly Twitter).

一款增强 X（原 Twitter）视频播放与下载体验的 Chrome 扩展。

## Features / 功能

- In-page theater mode / 网页内剧场模式
- Detect videos and show author/post details / 嗅探视频并显示博主与博文信息
- Choose available video quality / 选择可用清晰度
- Batch export selected videos to one ZIP / 将所选视频批量打包为 ZIP
- Chinese and English UI / 中英文界面

## Privacy / 隐私政策

## Install for development / 开发者安装

1. Download or clone this repository.
2. Open `chrome://extensions/` in Chrome.
3. Enable Developer mode.
4. Click **Load unpacked** and select the repository directory.

## Tests / 测试

Run `npm test` for the Node.js unit tests. Browser smoke tests under `tests/` require the additional browser test environment described in the scripts.
