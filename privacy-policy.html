1. 概述

X 视频助手是一款独立的浏览器扩展，为 X（原 Twitter）提供网页内剧场模式、视频识别、清晰度选择与单个或批量视频下载功能。本扩展不属于 X Corp. 官方产品。

2. 处理的信息及用途

为实现上述功能，扩展可能在您访问 X 网站时读取当前页面中已加载的博文 ID、博文摘要、作者昵称和头像链接，以及视频资源地址、时长、分辨率和文件大小等信息。此类信息用于展示视频列表、识别可用画质及处理您主动发起的下载。扩展不以建立个人画像或广告追踪为目的处理这些信息。

3. 本地存储

扩展通过 Chrome 存储机制保存默认画质和界面语言等偏好设置，并可临时存储批量下载任务所需的媒体链接和选择信息。您可以通过移除扩展或清除其数据来删除这些本地设置。

4. 网络请求和数据共享

为获取视频与博文信息，扩展可能请求 X 相关服务，包括 cdn.syndication.twimg.com 和 video.twimg.com，并加载博主头像等媒体资源。这些请求可能使相关服务获取正常网络请求中携带的技术信息（如 IP 地址）。扩展不将博文文本、下载内容或浏览行为发送到开发者自有的分析、广告或数据收集服务器，也不出售这些信息。

5. 下载与文件保存

视频下载由您主动触发。单个视频通过 Chrome 下载功能保存；批量导出会在本地生成 ZIP 文件。视频内容不会上传到开发者的转码服务器。文件保存位置和下载管理受浏览器及操作系统控制。

6. 权限

扩展使用 activeTab 与当前标签页交互，使用 downloads 保存文件，使用 storage 保存偏好和临时任务信息；与 X 视频及博文相关的主机权限用于访问必要媒体资源。

7. 第三方服务与未成年人

您在 X 平台上的活动仍受 X 自身条款与隐私政策约束。扩展不专门面向儿童，也不有意收集儿童个人信息。

8. 政策更新与联系

功能或数据处理方式发生实质变化时，本政策可能更新，并更新生效日期。有关本扩展的隐私问题，请通过其 Chrome 网上应用店商品页面提供的开发者支持渠道联系。

1. Overview

X Video Assistant is an independent browser extension for X (formerly Twitter), offering in-page theater mode, video detection, quality selection, and individual or batch video downloads. It is not affiliated with X Corp.

2. Information processed and purposes

To provide its features, the extension may read information already loaded on the X page, including post IDs, excerpts, author display names, avatar URLs, and video URLs, durations, resolutions, and file sizes. It uses this information to display detected videos, show available formats, and process downloads you initiate. It does not process this information for profiling or advertising tracking.

3. Local storage

The extension uses Chrome storage to retain preferences such as default quality and interface language, and may temporarily store media URLs and selections needed for batch download tasks. You can remove these locally stored settings by removing the extension or clearing its data.

4. Network requests and sharing

To retrieve post and media information, the extension may contact X-related services including cdn.syndication.twimg.com and video.twimg.com, and load media such as profile images. Those services may receive ordinary technical request information (such as your IP address). The extension does not send post text, downloaded media, or browsing activity to developer-operated analytics, advertising, or data-collection servers, and does not sell this information.

5. Downloads

Downloads occur when you request them. Individual files use Chrome downloads; batch exports create a ZIP file locally. Video files are not uploaded to any developer-operated transcoding server. Your browser and operating system control file saving and download management.

6. Permissions

The extension uses activeTab to interact with the active tab, downloads to save requested files, and storage to retain preferences and temporary task data. X-related host permissions provide access to the media and post resources necessary for these functions.

7. Third-party services and children

Use of X remains subject to X's terms and privacy policy. The extension is not designed specifically for children and does not knowingly collect children's personal information.

8. Updates and contact

If the extension's features or data processing materially change, this policy may be updated with a new effective date. For privacy-related questions, please use the developer support channel on the extension's Chrome Web Store listing.
